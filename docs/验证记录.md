## 真实网络与模拟测试的区分

使用本机预置密钥，在Edge直连 `GET /v1/models` 于2026-09-30 02:37（北京时间）返回HTTP 200，列出11个模型，含 `agnes-video-2.5-flash`。这证明当时该浏览器到模型列表接口的网络、CORS和认证可用，不证明余额、内容审核或所有CDN下载策略永远可用。

本次平台开发没有额外创建真实计费视频。生成、排队、超时、限流和失败路径使用可控模拟API；下载后的解码、抽帧、素材修正、哈希、文件写入和拼接使用真实浏览器与真实媒体引擎。测试图样不是AgnesAI生成结果。既有生产经验用于接口参数和恢复策略；上线后第一次生产建议先做一个4秒任务，再测试带图/声音的分镜。

## 复现

Node.js 20+，Python 3.10+，安装桌面版Edge。开发测试额外需要Playwright（网页用户无需安装）：

```powershell
npm install --no-save --package-lock=false playwright
node --test tests/core.test.mjs
python -m unittest discover -s tests -p "test_*.py"
```

分别保持以下两个终端运行：

```powershell
python tools/serve.py
python tools/serve.py --port 4175 --prefix /x-ai/
```

第三个终端执行：

```powershell
node tests/browser.mjs
```

测试只访问本地服务、使用隔离的浏览器上下文和OPFS测试目录；不会读取个人输出文件夹，也不使用真实KEY。`tests/fixtures/synthetic.mp4` 是可公开的合成测试片。详细结果和截图输出到被Git忽略的 `test-results/`。如果Playwright安装在其他目录，可设置 `PLAYWRIGHT_PATH`。

## 功能边界

未内置Whisper、AI视觉语义判片或声音克隆。片段的技术通过不等于人物、台词、口型、声音身份和剧情正确；用户需看听审核，或者导出复核提示词给外部工具。没有自动无限付费重做。

自动写目录需桌面Chrome/Edge及授权。保持页面和电脑运行；关闭页面后沿原video_id恢复。单次拼接输入上限450MB。跨域策略变化时可用随项目提供的本机连接器；直接API/公开Pages真实生产仍受第三方网络、额度与浏览器策略影响。

Pages实际发布由用户执行，本记录不把本地子路径测试写成已上线验收。
