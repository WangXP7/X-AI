# X-AI 1.2.0 · 本地视频创作台

一个可直接发布到 GitHub Pages 的静态视频生成操作平台。支持 Agnes Video 2.5 Flash 的文字、图像/声音参考、首尾帧模式，以及批量分镜、可恢复队列、本地校验和按集拼接。

完整产品、技术与交接设计见 [X-AI 详细设计文档（Markdown）](docs/X-AI详细设计文档.md)；人类阅读可直接双击 [HTML 阅读版](docs/X-AI详细设计文档.html)。文档包含界面、数据协议、递归引用、队列、校验、恢复、部署、限制与扩展方案，区分当前实现和后续设计。

网页不依赖对话AI或网站后台。提示词和你选择的素材在提交时发送给 AgnesAI；生成发生在服务商，下载、检查、文件管理和拼接发生在你的浏览器/电脑。**静态网页不等于离线生成模型。**

## 立即本地运行

需要 Windows、Python 3.10+、桌面版 Chrome 或 Edge。Python 只负责提供本地静态文件；发布到 Pages 后访问者无需 Python，除非他们需要可选的跨域连接器。

1. 双击 `启动X-AI.cmd`。工具会检查并启动本机服务，再自动打开浏览器；启动窗口可以关闭。
2. 首选地址为 **http://127.0.0.1:4183/**。已有 X-AI 服务会复用；端口被其他程序占用时自动选择空闲端口，实际地址显示在启动输出并保存在 `.local/startup.json`。以后优先复用这个地址。
3. 选择一个**输出文件夹**，推荐放在代码仓库外，防止误上传私人素材与视频。
4. 本机默认密钥自动启用；需要换 KEY 时，打开“连接与密钥”，粘贴新密钥并点“使用新密钥”。
5. 默认“小白版”：填写提示词、添加素材后点击“生成视频”，自动检查、优化图片、入队、生成、下载并保存。多段可导入文本/JSON/CSV，一次授权来源目录后自动读取引用。
6. 需要完整参数与分步控制时切换“专家版”。PavoAI标签提供紧凑输入框、素材＋ / @、模型选择和比例 / 时长 / 分辨率弹层。

命令行等价方式：

```powershell
python tools/launch.py
```

只检查 / 启动服务而不打开浏览器：`python tools/launch.py --no-browser`。需要指定首选端口：`python tools/launch.py --port 4183`。开发者仍可运行 `python tools/serve.py --port 4183` 使用前台服务，此方式需保持终端运行。

电脑重启后，再双击启动入口即可。若收藏地址出现“127.0.0.1 拒绝连接”，先运行启动入口。服务只提供静态文件；关闭网页会停止浏览器内的队列操作，重新打开后先恢复记录与目录授权，再按原任务编号继续查询。不同端口的浏览器数据独立；若被迫换端口，从本地制作记录恢复。

启动记录和日志在 Git 忽略的 `.local/` 中，不含 API KEY 或素材。不能直接双击 `index.html`：`file://` 不提供完整的模块、加密和文件系统权限环境。

## 默认密钥与自己的密钥

本机版本已配置默认密钥，**打开网页自动启用，无需口令**。在“连接与密钥”中可以直接粘贴自己的 KEY，点 **使用新密钥** 即可切换；点 **使用默认密钥** 可以切回。新输入的密钥只在本次打开期间有效，关闭或刷新后恢复默认。

**高级模式** 默认收起，只有需要长期加密保存、口令解锁、备份/导入或调整连接方式时才展开。原来的密码保险箱和取口令工具继续保留。错误提示固定显示在弹窗底部，不受遮罩影响。

本机自动使用配置为 `private/default-access.json`，API KEY 使用 AES-GCM 封装，不以明文写入文件。为了免口令使用，开启封装所需的数据也在本机配置中：**持有完整 private 目录的人可以恢复和使用默认密钥，这不是能公开发布的保密方案**。该目录被 Git 忽略，不能手动上传。

公开 GitHub Pages 版本不含你的私人默认密钥，访客填写自己的 KEY；界面会明确提示该版本未配置默认密钥。无需口令的私人配置和需要用户口令的加密备份是两种不同的保存方式。

日常操作、高级模式与备份说明见 [密钥使用说明](docs/密钥使用说明.md)。

## 批量素材操作

在 **本地素材库 → 添加素材** 选择多个文件后，会先显示校验清单。点击 **开始校验并导入**，即可看到当前文件、处理阶段、完成数量以及逐项结果。支持完成当前项后停止、继续剩余项、重试失败项和下载处理记录。

素材卡片默认等比显示全图，长横图使用更宽的卡片。点击图片可适应窗口、查看原始尺寸或放大查看。勾选卡片后，可 **批量优化图片**、**批量下载 ZIP** 或 **用于当前分镜**；素材库的多选与当前分镜的参考列表分别管理。

图片优化保留原文件名和实际 PNG/JPEG/WebP 格式，另存到 `references/optimized/原素材ID/版本ID/原文件名` 并重新校验；尚未提交的无尝试分镜采用有效替代，已提交和已生成记录保留。声音不自动裁切。ZIP 保留原文件字节和文件名，以 `assets/素材ID/原文件名` 子目录区分同名文件，并附带含来源与哈希的素材清单；单次最多 500MB。完整说明见 [素材操作说明](docs/素材操作说明.md)。

## 独立的单段与多段操作区

单段模式使用蓝绿色操作按钮，填写一镜的提示词、参数和素材；多段模式使用紫色工作区，直接导入 / 粘贴分镜清单，不显示单段操作框。切换时各自保留本页的输入和素材选择。

批量页面的 **批量默认设置** 默认收起，可设置缺省时长、画幅、分组、自动镜号前缀和共用参考素材。清单已写明的参数优先，明确空的素材列不使用参考。单段的对白、种子、首尾帧与选择不会混入批量任务。

左下角版本行显示 **X-AI 1.1.6　® YiQiXP**，保持紧凑布局。

其下显示“让X-AI和你创造属于你的故事”，采用与整体一致的字体，分成完整的两行。操作指南使用书本图标，本地标语明确分为“你的文件，”“你的电脑”两行。表单底部模型下拉显示平台、模型版本、720P 与最长 12 秒，目前只有已接入的 Flash 一项。

## 1.1 新增创作项目与素材关联

工作台顶部的 **全新项目 / 项目选择** 管理独立草稿和素材库范围；任务与成片仍显示全部项目，队列、历史视频和输出目录保留。各项目分组应不同，镜号仍全局唯一。切回项目或刷新可恢复草稿；批量源目录需重新选择并展开引用。

提示词标签为 **画面与动作描述【提示词Prompt】**。写入素材完整文件名后，点 **自动关联素材库**；优先使用有效优化版本，同名来源不唯一时提示填写准确路径或手动选择。默认单段为图像 / 声音参考、12秒、16:9横屏，无素材仍需补齐或主动改成文字生成。

素材库按 **版本、图片 / 声音、校验状态、文件名 / 编号 / 路径** 组合筛选。默认只显示当前有效版本，优化前原图仍可在“原始素材”筛选中查看。**清空素材库**移除当前项目成员，可恢复；不删除本地文件、生成任务或历史。**取消选择**只取消勾选。

导入完成后的 **选中结果并打开素材库** 用于勾选本轮素材，便于批量操作；**关闭结果**只关闭窗口。文件已保存，两个按钮均不代表重新导入，也不自动将全库加入分镜。

## 1.1.1 新增试听与试看互斥

## 1.1.2 本地启动与连接恢复

本地启动器独立运行静态服务，重复点击复用当前项目，不再依赖开发工具中的临时终端。身份检查同时核对应用和工程目录；不会停止其他程序来抢占端口。启动记录原子保存，重复点击由本机文件锁串行处理。

可选连接器自动读取启动记录中的本地端口；先启动 X-AI，再双击 `启动本机连接器.cmd`。使用前台服务或后来更换端口时，可运行 `python tools/connector.py --local-port 4183`，按实际端口修改并重新配对。连接器仍需保持自己的终端运行。

本轮维护设计见 **第29章（1.1.2）**，验证结果见 [验证记录](docs/验证记录.md)。

## 1.1.3 原素材只引用与导入错误恢复

手动添加、拖放和CSV路径引用统一采用原文件引用：不往references另存未修改素材，不添加文件名前缀，不修改源文件。浏览器保留预览 / 校验缓存；点击“添加素材”会优先保存原文件只读句柄。只将优化、补边或裁切结果保存为 `references/optimized/原素材ID/版本ID/原文件名`，映射同步到project.json、reference-mapping.json和尚未提交分镜。

旧版references文件名之前的12位字符是内容哈希。新版本不生成这种前缀；兼容升级保留原素材ID、旧路径别名、缓存及历史尝试，不删除旧文件。需要关联实际源文件时重新选择原件，同名且SHA相同会复用已有素材和引用。通过旧文件名恢复仍核对哈希，不能只凭名称假定内容一致。

原文件不可读取时显示简短中文原因，可“重新选择原文件”后“重试失败项”。目录保存失败时保留浏览器记录、暂停剩余处理，并提供“重试目录保存”；不用重新导入整批。导入先取得当前源File并读取稳定字节，再统一校验、哈希和缓存；目录写入串行，写入前先读取File内容，减少文件状态变化引发的错误。

完整设计、边界及实际测试见 **第30章（1.1.3）** 和 [素材操作说明](docs/素材操作说明.md)。

## 1.1.4 目录保存反复报错修复

上次修复了原素材读取、串行写入与中文提示，但没有重试短暂失效的目录写入。现在每次重试重新获取目标文件句柄，短暂状态错误最多尝试5次，间隔150、450、1000、2000毫秒；每次成功提交后回读核对SHA-256。若关闭流后报错但字节已经正确，则直接确认保存，不重复写入。

批量导入仍逐项保存project.json检查点；reference-mapping.json在本轮结束 / 停止时集中刷新，内容相同不再重复写。最终映射保存完成前保持忙碌，失败显示“目录保存待重试”，保留浏览器记录。点击“重试目录保存”只补落盘，不重新导入或重新生成视频。持续失败可重新选择输出目录；权限拒绝、空间不足不自动盲重试。

“下载处理记录”包含本轮文件相对路径、失败阶段（打开 / 写入 / 提交 / 核验）、错误代码和尝试次数，便于定位持续问题。浏览器最多保留50条目录异常诊断，不记录素材字节或API密钥。此次本地重试与云端API提交完全分开，已有video_id和历史尝试保持。详细设计新增第31章。

## 1.1.5 任务刷新与动态进度

“任务与成片”筛选旁增加“刷新状态”。运行中的队列只刷新显示，继续按原请求间隔追踪；队列停止且有未终止的已知video_id时，刷新只查询一次原任务，不提交待生成镜头，也不自动开始下载。刷新中的重复点击合并，请求仍遵守至少90秒间隔及退避；等待时有倒计时，刷新完成后可点“开始 / 继续队列”恢复后续下载和校验。

顶部展示全部 / 已生成 / 处理中 / 待提交 / 需处理数量和真实已生成占比；当前镜头显示阶段、任务已用时间、最近服务端响应时间。等待间隔、查询、下载字节、五点抽帧、完整解码和拼接有动态提示。服务端提供合法百分比才显示；未知时显示活动条，不虚构完成比例或预计完成时间。每秒只更新进度文字，不重建视频预览。状态未更新不等于已完成，服务端排队时间无法由网页保证。

详细设计新增第32章，旧1.1.4目录修复记录保留。页面内“刷新状态”不同于浏览器刷新；浏览器重新加载会中断本地追踪，应先结束 / 停止本地操作。

## 分镜引用其他文件

选择清单与素材的共同上级目录，在下拉框选 CSV，再点 **读取引用并展开**。提示词 / 对白支持 TXT、Markdown、JSON、CSV 多层引用，按镜号、标题或 JSON 字段取内容；图片与声音按每层文件所在目录定位。页面展示替换前后与来源，循环、缺失或歧义会阻止整批入队。

完整语法、目录示例和处理限制见 [批量清单与路径引用](docs/批量清单与路径引用.md)。

## 功能与状态

|环节|实际行为|
|---|---|
|单段生成|提示词、对白、种子、时长、画幅，文字/参考/首尾帧三种模式|
|多段生成|文本 / JSON / CSV / TSV；递归展开外部提示词、对白及素材清单，预览后按序运行|
|素材检查|真实解码图片/声音，检查大小、尺寸、比例、数量、音频总长、编号映射|
|本地修正|图片等比缩放 / 补边；音频按指定时间裁切；原路径引用素材尽量保持同名及原编码，另存新版本|
|任务状态|素材检查、待提交、提交中、排队、生成中、下载、校验、已生成、审核通过、待处理/重做|
|连续镜头|上一镜**当前版本**的真实末帧作为下一镜参考，记录来源视频和末帧哈希|
|限流|所有认证HTTP至少间隔90秒，单任务串行；明确限流/队列满时递增退避|
|断点恢复|写入提交前检查点；保存video_id；GET失败继续原编号；POST不明停止并核实|
|结果校验|MP4签名、字节数、SHA-256、时长、比例、分辨率、五点抽帧、FFmpeg完整解码、音轨/帧率信息|
|人工审核|看视频、听对白、标记不合格原因、确认内容通过、导出AI复核提示词|
|修订|修改提示词/对白/时长/画幅/素材后保存新版本；历史API任务、文件和QA保留|
|按集拼接|只用当前视频路径，统一24fps和48k音频；合成MP4，再完整解码并检查总时长|
|过程记录|持续更新 `project.json` 与MD，可导出，支持换电脑从本地文件夹恢复|

“素材审核通过”只表示输入格式、参数符合程序规则；“技术通过”只表示媒体检查通过。两者都不代表人物、剧情、动作、口型或声音身份正确。

本版本**没有内置语音识别模型**。它不会将画面描述当成识别出的台词，也不会伪造Whisper通过记录。对白需人工听审，或导出复核提示词给外部AI。角色重绘、音色克隆、表演调整和复杂分镜拆解需借助相应工具。

## 已验证的接口约束

- API：`https://api.agnes-ai.cn`；备用已知源 `https://apihub.agnes-ai.com`。
- 模型固定 `agnes-video-2.5-flash`，`size=720P`、`n=1`。
- `POST /v1/videos` 创建；`GET /agnesapi?video_id=...&model_name=agnes-video-2.5-flash` 查询。
- 秒数字符串 `"4"`—`"12"`；不把长镜直接截成12秒，也不自动假设拆镜内容。
- 参考模式最多5张图片、3段声音，声音总长2–12秒，单文件小于15MB。
- 图像宽高256–5760，宽高比0.4–2.5，PNG/JPEG/WebP。
- 本地图片声音转Data URI提交，不要求你先上传到网盘或图床。
- 16:9 Flash常见实际输出为1280×704；平台按实际规格校验，不假装是1280×720。
- 视频参考输入不在本版支持范围。
- 每次POST、GET、连接测试均计入90秒间隔。只有明确返回 `rate_limit_exceeded` 或 `video_queue_full` 的创建拒绝允许自动退避重试。其他提交不明先核实。

公开文档：[Flash模型说明](https://wiki.agnes-ai.com/en/docs/agnes-video-25-flash)。价格、余额、并发、账户权限以你的服务商控制台为准，平台不把历史促销信息写成永久免费承诺。

## 本地文件结构

```text
你选择的输出目录/
  project.json                  # 执行状态、素材哈希、每次尝试、当前版本
  X-AI_制作过程与结果.md          # 持续更新，可给其他人或AI复用
  references/                   # 仅优化 / 裁切后的同名派生版本（原件不复制）
  reference-mapping.json        # 原素材路径到当前优化版的映射
  backups/                     # references 备份与覆盖前历史
  raw/EP01/                     # 原始下载
  clips/EP01/                   # 当前/历史分镜文件
  checks/S01_v1/                # 抽帧、真实末帧、检查报告
  episodes/                     # 分集MP4及实际输入清单
```

浏览器 IndexedDB 保存工作副本和已授权目录句柄；任务启动前检查点必须写入所选文件夹。浏览器不能绕过操作系统权限，刷新后可能需要“重新授权”。取消目录授权时会停止危险的后续操作并提示处理。

换电脑：复制完整输出目录 → 新电脑打开X-AI → 选择该目录 → 确认恢复检测到的项目 → 逐文件核验哈希并载入 → 单独启用自己的密钥。不要只复制JSON却漏掉媒体文件。取消恢复不会覆盖原有记录；“恢复项目”按钮也可导入另存的检查点JSON。

同一网站在同一浏览器只允许一个可操作窗口，避免两个页面同时生成。多个不同网站、浏览器、设备或其他程序使用同一API账户时，平台无法统一协调它们，请勿同时运行。

## 发布到 GitHub Pages

仓库内是**直接可发布的静态文件**，无需npm安装、构建、Node服务器或云端密钥。约32MB的单线程FFmpeg WASM已随仓库提供，所有导入使用相对路径，支持仓库子路径。

1. 在GitHub创建一个空仓库，例如 `x-ai`。不要先自动创建README，以免第一次推送出现分支冲突。
2. 本地仓库已建立。确认私人目录没有进入Git：

   ```powershell
   git status
   git ls-files private .local
   ```

   第二条应没有私人文件输出。

3. 本地Git已初始化为 `main`，已有初始提交。先用 `git status` 和 `git log -1` 确认当前状态；有待提交修改时再提交。需要配置身份时使用自己的姓名与邮箱（可使用GitHub隐私邮箱）：

   ```powershell
   git config user.name "YOUR_NAME"
   git config user.email "YOUR_GITHUB_EMAIL"
   git add README.md docs tools/build-design-doc.mjs
   git commit -m "Document X-AI detailed design"
   git remote add origin https://github.com/YOUR_NAME/x-ai.git
   git push -u origin main
   ```

   若提示需登录，使用Git Credential Manager/GitHub CLI；不要把访问令牌写进远程URL或提交文件。

4. GitHub仓库 → **Settings → Pages → Build and deployment**，选择 **Deploy from a branch**，分支 **main**，目录 **/(root)**，保存。
5. 等Pages部署完成，访问 `https://YOUR_NAME.github.io/x-ai/`。仓库 `.nojekyll` 会避免Jekyll处理静态文件。
6. 验证Logo、素材导入、密钥设置、连接测试、深度校验是否正常，再开始生产。

如已有远程，改用 `git remote set-url origin ...`。如果Git询问提交身份，配置你自己的 `git config user.name` 和 `git config user.email`，不要照抄开发者身份。完整发布检查见 [部署说明](docs/部署与准备清单.md)。

请用Git推送：浏览器上传单文件有25MB限制，媒体引擎WASM约32MB。不要拖拽上传整个工作目录，里面含被Git忽略的私人保险箱。`vendor/source` 保存第三方源码与许可证材料，不由网页自动加载，请随项目保留。

## 跨域失败时的本机连接器

2026-09-30实测：本机Edge浏览器能直连模型列表接口，默认密钥认证返回200并列出Flash模型。CORS或本地网络策略可能变化，因此保留可选连接器。

```powershell
# 本地网页
python tools/connector.py

# 访问 GitHub Pages 的用户（改成自己实际的网址源，不含仓库路径）
python tools/connector.py --origin https://YOUR_NAME.github.io
```

打开“连接与密钥 → 高级模式 → 高级连接设置”，填入控制台配对码，切换“本机连接器”。允许浏览器提示的本地网络访问权限。连接器只监听127.0.0.1:4174，校验页面来源和随机配对码，只转发两个固定Agnes域名的必要API；不保存KEY，不给CDN下载携带Authorization。每次重启更换配对码。Pages的Python脚本只作为可下载工具文件，不会在GitHub服务器运行。

它是解决第三方CORS限制的可选本机程序，不是网页后端依赖。如果浏览器直连成功，无需运行。

## 使用边界

- 自动写目录需桌面Chrome/Edge；Firefox、Safari和部分内嵌浏览器不支持同等文件系统API。
- 页面关闭、电脑休眠或浏览器冻结时不能持续运行。已提交云端任务可能继续，重新打开后沿原编号恢复。
- 完整解码和拼接使用CPU/WASM，有内存开销。单次拼接最多450MB输入；数百镜请按集处理。
- 当前拼接要求同组同画幅、每镜音轨存在且技术通过；超长项目可导出记录交给桌面FFmpeg处理。
- 不自动补出低清素材中不存在的细节，不自动克隆人声，不代替人工艺术审核。
- 内容不合格不会自动触发无限付费重做；每次修订保留原因，新任务由用户启动队列。

## 1.1.6 紧凑进度与下载故障恢复

任务页把筛选、刷新和统计放在同一行，整体 / 当前进度并排；阶段与时间按需展开。空队列不显示会动的假进度，整体统计改称“已就绪”，以免把服务端生成完成与本地核验完成混淆。

生成API成功不代表视频CDN允许网页下载。收到completed和URL后下载失败，显示“已生成 · 下载待恢复”，在任务卡点“重试下载”或“下载帮助”。本地版本直连CDN失败时会自动使用同源本机下载通道，只读取固定Agnes视频CDN，不传KEY、不创建任务。GitHub Pages需开启本机连接器并配对，或在详情打开原视频下载后点“导入已下载视频”。不要因下载失败重新生成。

本次新增Python模块tools/local_media.py。更新本机工具后需重新启动“启动X-AI.cmd”，刷新确认1.1.6；同一网址的浏览器数据保留。页面启动会先核验同一项目的较新磁盘记录，避免把旧浏览器副本盖回恢复结果。若媒体 / 素材核验失败则停止目录写入并提示重新选择原目录，不忽略哈希。

具体故障分析、代理兼容限制和验证见详细设计第33章。

## 1.2.0 小白版、专家版与 PavoAI

小白版只需要提示词和必要素材。没有素材自动采用文字生成；有素材采用图片 / 声音参考。不合规图片按既有等比缩放 / 补边策略自动同名另存，声音不会擅自裁切。无需逐次确认校验、入队、开始与下载。首次本地保存仍需浏览器目录授权，缺失、歧义和未知提交仍明确提示。专家版保留分步操作。三种创作标签的操作区和草稿独立；全局任务与成片不因切换而丢失。

时长优先读提示词：JSON `seconds / duration` 或明确“视频时长7秒”等。没有明确声明才使用界面 / CSV时长。超过当前接口能力的请求不会截剧情或悄悄改成12秒。返回视频按真实时长直接采用，超过12秒或与请求不等不要求二次处理。完整解码、画幅等技术检查保持。

当前已集成 AgnesAI / Agnes Video 2.5 Flash / 720P。这一配置的各模式请求为4–12秒。`src/models.js`按平台、模型与模式管理能力，侧栏平台名、模型标签、时长选项、校验与API模型值均读取配置。PavoAI是界面模式；后续平台须补能力和适配器后才加入选项。详见设计文档第34章。
