# X-AI · 本地视频创作台

一个可直接发布到 GitHub Pages 的静态视频生成操作平台。支持 Agnes Video 2.5 Flash 的文字、图像/声音参考、首尾帧模式，以及批量分镜、可恢复队列、本地校验和按集拼接。

网页不依赖对话AI或网站后台。提示词和你选择的素材在提交时发送给 AgnesAI；生成发生在服务商，下载、检查、文件管理和拼接发生在你的浏览器/电脑。**静态网页不等于离线生成模型。**

## 立即本地运行

需要 Windows、Python 3.10+、桌面版 Chrome 或 Edge。Python 只负责提供本地静态文件；发布到 Pages 后访问者无需 Python，除非他们需要可选的跨域连接器。

1. 双击 `启动X-AI.cmd`，保持窗口运行。
2. 打开 **http://127.0.0.1:4173**。
3. 选择一个**输出文件夹**，推荐放在代码仓库外，防止误上传私人素材与视频。
4. 本机默认密钥自动启用；需要换 KEY 时，打开“连接与密钥”，粘贴新密钥并点“使用新密钥”。
5. 单段填写，或切换多段导入文本/JSON/CSV。检查通过后到“任务与成片”点击开始。

命令行等价方式：

```powershell
cd D:\68.AIGC\xAi-videoGen
python tools/serve.py
```

不能直接双击 `index.html`：`file://` 不提供完整的模块、加密和文件系统权限环境。

## 默认密钥与自己的密钥

本机版本已配置默认密钥，**打开网页自动启用，无需口令**。在“连接与密钥”中可以直接粘贴自己的 KEY，点 **使用新密钥** 即可切换；点 **使用默认密钥** 可以切回。新输入的密钥只在本次打开期间有效，关闭或刷新后恢复默认。

**高级模式** 默认收起，只有需要长期加密保存、口令解锁、备份/导入或调整连接方式时才展开。原来的密码保险箱和取口令工具继续保留。错误提示固定显示在弹窗底部，不受遮罩影响。

本机自动使用配置为 `private/default-access.json`，API KEY 使用 AES-GCM 封装，不以明文写入文件。为了免口令使用，开启封装所需的数据也在本机配置中：**持有完整 private 目录的人可以恢复和使用默认密钥，这不是能公开发布的保密方案**。该目录被 Git 忽略，不能手动上传。

公开 GitHub Pages 版本不含你的私人默认密钥，访客填写自己的 KEY；界面会明确提示该版本未配置默认密钥。无需口令的私人配置和需要用户口令的加密备份是两种不同的保存方式。

日常操作、高级模式与备份说明见 [密钥使用说明](docs/密钥使用说明.md)。

## 批量素材操作

在 **本地素材库 → 添加素材** 选择多个文件后，会先显示校验清单。点击 **开始校验并导入**，即可看到当前文件、处理阶段、完成数量以及逐项结果。支持完成当前项后停止、继续剩余项、重试失败项和下载处理记录。

素材卡片默认等比显示全图，长横图使用更宽的卡片。点击图片可适应窗口、查看原始尺寸或放大查看。勾选卡片后，可 **批量优化图片**、**批量下载 ZIP** 或 **用于当前分镜**；素材库的多选与当前分镜的参考列表分别管理。

图片优化会另存并重新校验，不覆盖原图或已有分镜。声音不自动裁切。ZIP 保留原文件字节、处理同名文件，并附带含来源与哈希的素材清单；单次最多 500MB。完整说明见 [素材操作说明](docs/素材操作说明.md)。

## 独立的单段与多段操作区

单段模式使用蓝绿色操作按钮，填写一镜的提示词、参数和素材；多段模式使用紫色工作区，直接导入 / 粘贴分镜清单，不显示单段操作框。切换时各自保留本页的输入和素材选择。

批量页面的 **批量默认设置** 默认收起，可设置缺省时长、画幅、分组、自动镜号前缀和共用参考素材。清单已写明的参数优先，明确空的素材列不使用参考。单段的对白、种子、首尾帧与选择不会混入批量任务。

左下角版本行显示 **X-AI 1.0　® YiQiXP**，保持紧凑布局。

## 分镜引用其他文件

选择清单与素材的共同上级目录，在下拉框选 CSV，再点 **读取引用并展开**。提示词 / 对白支持 TXT、Markdown、JSON、CSV 多层引用，按镜号、标题或 JSON 字段取内容；图片与声音按每层文件所在目录定位。页面展示替换前后与来源，循环、缺失或歧义会阻止整批入队。

完整语法、目录示例和处理限制见 [批量清单与路径引用](docs/批量清单与路径引用.md)。

## 功能与状态

|环节|实际行为|
|---|---|
|单段生成|提示词、对白、种子、时长、画幅，文字/参考/首尾帧三种模式|
|多段生成|文本 / JSON / CSV / TSV；递归展开外部提示词、对白及素材清单，预览后按序运行|
|素材检查|真实解码图片/声音，检查大小、尺寸、比例、数量、音频总长、编号映射|
|本地修正|图片等比缩放 / 补边；音频按指定时间裁切；原路径引用素材尽量保持同名及原编码，另存新版本|
|任务状态|素材检查、待提交、提交中、排队、生成中、下载、校验、已生成、审核通过、待处理/重做|
|连续镜头|上一镜**当前版本**的真实末帧作为下一镜参考，记录来源视频和末帧哈希|
|限流|所有认证HTTP至少间隔90秒，单任务串行；明确限流/队列满时递增退避|
|断点恢复|写入提交前检查点；保存video_id；GET失败继续原编号；POST不明停止并核实|
|结果校验|MP4签名、字节数、SHA-256、时长、比例、分辨率、五点抽帧、FFmpeg完整解码、音轨/帧率信息|
|人工审核|看视频、听对白、标记不合格原因、确认内容通过、导出AI复核提示词|
|修订|修改提示词/对白/时长/画幅/素材后保存新版本；历史API任务、文件和QA保留|
|按集拼接|只用当前视频路径，统一24fps和48k音频；合成MP4，再完整解码并检查总时长|
|过程记录|持续更新 `project.json` 与MD，可导出，支持换电脑从本地文件夹恢复|

“素材审核通过”只表示输入格式、参数符合程序规则；“技术通过”只表示媒体检查通过。两者都不代表人物、剧情、动作、口型或声音身份正确。

本版本**没有内置语音识别模型**。它不会将画面描述当成识别出的台词，也不会伪造Whisper通过记录。对白需人工听审，或导出复核提示词给外部AI。角色重绘、音色克隆、表演调整和复杂分镜拆解需借助相应工具。

## 已验证的接口约束

- API：`https://api.agnes-ai.cn`；备用已知源 `https://apihub.agnes-ai.com`。
- 模型固定 `agnes-video-2.5-flash`，`size=720P`、`n=1`。
- `POST /v1/videos` 创建；`GET /agnesapi?video_id=...&model_name=agnes-video-2.5-flash` 查询。
- 秒数字符串 `"4"`—`"12"`；不把长镜直接截成12秒，也不自动假设拆镜内容。
- 参考模式最多5张图片、3段声音，声音总长2–12秒，单文件小于15MB。
- 图像宽高256–5760，宽高比0.4–2.5，PNG/JPEG/WebP。
- 本地图片声音转Data URI提交，不要求你先上传到网盘或图床。
- 16:9 Flash常见实际输出为1280×704；平台按实际规格校验，不假装是1280×720。
- 视频参考输入不在本版支持范围。
- 每次POST、GET、连接测试均计入90秒间隔。只有明确返回 `rate_limit_exceeded` 或 `video_queue_full` 的创建拒绝允许自动退避重试。其他提交不明先核实。

公开文档：[Flash模型说明](https://wiki.agnes-ai.com/en/docs/agnes-video-25-flash)。价格、余额、并发、账户权限以你的服务商控制台为准，平台不把历史促销信息写成永久免费承诺。

## 本地文件结构

```text
你选择的输出目录/
  project.json                  # 执行状态、素材哈希、每次尝试、当前版本
  X-AI_制作过程与结果.md          # 持续更新，可给其他人或AI复用
  references/                   # 手动导入的管理副本、优化后的派生版本
  reference-mapping.json        # 原素材路径到当前优化版的映射
  backups/                     # references 备份与覆盖前历史
  raw/EP01/                     # 原始下载
  clips/EP01/                   # 当前/历史分镜文件
  checks/S01_v1/                # 抽帧、真实末帧、检查报告
  episodes/                     # 分集MP4及实际输入清单
```

浏览器 IndexedDB 保存工作副本和已授权目录句柄；任务启动前检查点必须写入所选文件夹。浏览器不能绕过操作系统权限，刷新后可能需要“重新授权”。取消目录授权时会停止危险的后续操作并提示处理。

换电脑：复制完整输出目录 → 新电脑打开X-AI → 选择该目录 → 确认恢复检测到的项目 → 逐文件核验哈希并载入 → 单独启用自己的密钥。不要只复制JSON却漏掉媒体文件。取消恢复不会覆盖原有记录；“恢复项目”按钮也可导入另存的检查点JSON。

同一网站在同一浏览器只允许一个可操作窗口，避免两个页面同时生成。多个不同网站、浏览器、设备或其他程序使用同一API账户时，平台无法统一协调它们，请勿同时运行。

## 发布到 GitHub Pages

仓库内是**直接可发布的静态文件**，无需npm安装、构建、Node服务器或云端密钥。约32MB的单线程FFmpeg WASM已随仓库提供，所有导入使用相对路径，支持仓库子路径。

1. 在GitHub创建一个空仓库，例如 `x-ai`。不要先自动创建README，以免第一次推送出现分支冲突。
2. 本地仓库已建立。确认私人目录没有进入Git：

   ```powershell
   cd D:\68.AIGC\xAi-videoGen
   git status
   git ls-files private .local
   ```

   第二条应没有私人文件输出。

3. 本地Git已初始化为 `main`，文件已暂存。此电脑尚未配置提交身份，因此首次提交留给你完成。把占位内容换成自己的（可使用GitHub隐私邮箱）：

   ```powershell
   git config user.name "YOUR_NAME"
   git config user.email "YOUR_GITHUB_EMAIL"
   git commit -m "Initial X-AI video studio"
   git remote add origin https://github.com/YOUR_NAME/x-ai.git
   git push -u origin main
   ```

   若提示需登录，使用Git Credential Manager/GitHub CLI；不要把访问令牌写进远程URL或提交文件。

4. GitHub仓库 → **Settings → Pages → Build and deployment**，选择 **Deploy from a branch**，分支 **main**，目录 **/(root)**，保存。
5. 等Pages部署完成，访问 `https://YOUR_NAME.github.io/x-ai/`。仓库 `.nojekyll` 会避免Jekyll处理静态文件。
6. 验证Logo、素材导入、密钥设置、连接测试、深度校验是否正常，再开始生产。

如已有远程，改用 `git remote set-url origin ...`。如果Git询问提交身份，配置你自己的 `git config user.name` 和 `git config user.email`，不要照抄开发者身份。完整发布检查见 [部署说明](docs/部署与准备清单.md)。

请用Git推送：浏览器上传单文件有25MB限制，媒体引擎WASM约32MB。不要拖拽上传整个工作目录，里面含被Git忽略的私人保险箱。`vendor/source` 保存第三方源码与许可证材料，不由网页自动加载，请随项目保留。

## 跨域失败时的本机连接器

2026-09-30实测：本机Edge浏览器能直连模型列表接口，默认密钥认证返回200并列出Flash模型。CORS或本地网络策略可能变化，因此保留可选连接器。

```powershell
# 本地网页
python tools/connector.py

# 访问 GitHub Pages 的用户（改成自己实际的网址源，不含仓库路径）
python tools/connector.py --origin https://YOUR_NAME.github.io
```

打开“连接与密钥 → 高级模式 → 高级连接设置”，填入控制台配对码，切换“本机连接器”。允许浏览器提示的本地网络访问权限。连接器只监听127.0.0.1:4174，校验页面来源和随机配对码，只转发两个固定Agnes域名的必要API；不保存KEY，不给CDN下载携带Authorization。每次重启更换配对码。Pages的Python脚本只作为可下载工具文件，不会在GitHub服务器运行。

它是解决第三方CORS限制的可选本机程序，不是网页后端依赖。如果浏览器直连成功，无需运行。

## 使用边界

- 自动写目录需桌面Chrome/Edge；Firefox、Safari和部分内嵌浏览器不支持同等文件系统API。
- 页面关闭、电脑休眠或浏览器冻结时不能持续运行。已提交云端任务可能继续，重新打开后沿原编号恢复。
- 完整解码和拼接使用CPU/WASM，有内存开销。单次拼接最多450MB输入；数百镜请按集处理。
- 当前拼接要求同组同画幅、每镜音轨存在且技术通过；超长项目可导出记录交给桌面FFmpeg处理。
- 不自动补出低清素材中不存在的细节，不自动克隆人声，不代替人工艺术审核。
- 内容不合格不会自动触发无限付费重做；每次修订保留原因，新任务由用户启动队列。

## 批量清单与本地路径

CSV 支持中文表头、逗号 / 制表符 / 分号 / 竖线、引号内换行。选择清单与素材的共同上级目录后，可一次读取各镜明确的素材路径或编号，无需逐个添加。原素材直接引用，优化结果保留文件名存到 references，并自动记录替代关系。选输出目录时会先备份已有 references 文件、核对哈希；失败则停止写入。

参见 [批量清单与路径引用](docs/批量清单与路径引用.md) 与 [素材操作说明](docs/素材操作说明.md)。模式标签采用实底、勾选与面板色带，并支持左右方向键切换。
